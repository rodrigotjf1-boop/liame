Autorizações

Cada autorização é o "sim" que alguém deu na Meta, no Google, no Regem ou no RegemCast. Revogar para a leitura de todas as contas dela.

    Conectar plataforma

    Você vai para a página da plataforma, confirma lá e volta para cá. Na Meta e no Google, o Liame só lê: não cria, não muda e não gasta nada. No Regem, a única escrita possível é o cupom de campanha, sempre com aprovação.

    Escolher contas para Mister Burgers

    Google Ads
    Google Analytics (GA4)

    A primeira leitura traz os últimos 90 dias e leva alguns minutos. Depois, os números são atualizados todo dia.

    Revogar a autorização?

    A leitura das 2 contas desta autorização para agora. O histórico de números fica.

    Na Meta, para tirar o acesso de vez, remova também o app Liame em Configurações do negócio → Integrações → Apps conectados.

    No Google, o acesso é revogado lá também, na hora.

    No Regem, o token de cada loja é revogado na hora, dos dois lados. O que já foi lido segue o prazo de guarda.

    No RegemCast, o acesso é revogado na hora, dos dois lados. O que já foi lido segue o prazo de guarda.

    Conectar o Regem

    Você vai ao Regem escolher as lojas; o Liame recebe só o que estiver marcado.

    1. Entre no Regem com o perfil de presidente. O custo dos itens só sai com permissão financeira.
    2. Escolha as lojas e confira o que cada uma libera.
    3. Volte para cá e ligue cada loja do Regem a uma loja do Liame.

    O que o Liame pede

      O que o Liame nunca recebe

      • Nome e e-mail de cliente.
      • O telefone em si: ele vira um identificador pseudonimizado na chegada e não fica guardado.
      • Qualquer identificador de cliente de iFood, 99Food e Keeta.

      Nenhuma senha ou token passa por você: o Regem entrega o acesso direto ao Liame, com um token para cada loja. Você revoga quando quiser, aqui ou no Regem.

          Conectar o RegemCast

          Você vai ao RegemCast escolher o número do WhatsApp; o Liame recebe só as conversas abertas por anúncio.

          O que o Liame pede

            Só número na API oficial do WhatsApp manda de qual anúncio veio a conversa. Se o número estiver fora dela, o Liame avisa aqui, e a medição segue pelo link do cardápio e pelo cupom.
